## 3. OSS-vetted model tips (applies to both MMH3 + Wan)

- **Steps / CFG / resolution / sampling:** H3 Wavespeed — `steps 28, CFG 6.5, sampler dpmpp_2m, LUT tetrahedral` (VeilWick house grade, §5c). Wan2.1-14B native — `guidance_scale 5.0, flow_shift 5.0 @720p` (3.0 @480p), 16 fps; keep `sample_shift` in 8–12 range only if tuning per Kombitz/Wan repo. Don’t chase CFG >8 — it pushes contrast + carton-ish. Poster pipeline stays at `size "720*1280"` independent of video.
- **Duration:** H3 `4–15` (feed `5`); Wan `81 frames 4n+1` = 5.06s@16fps. For 60s episode, chain FLF with 16–24 overlap or Wavespeed `duration:60` which chunks internally.
- **Resolution:** feed `768p 9:16` native then `ffmpeg scale 768→720 lanczos + yuv420p + crf 23` for delivery; H3 accepts `2K` but Wavespeed feed bills at 768p (`$0.25/5s` I2V, `$0.30` R2V).
- **Negative discipline:** keep studio negatives strict (see Wan canonical line), but when deliberately prompting `high ISO / JPEG artifacts / soft shadows` for phone-candid, **remove** the artifact term from negative. Never put `cinematic 8k / perfect studio` and `RAW iPhone / compression artifacts` in the same prompt.
- **Candid realism discipline:** write one *incomplete action* (`hand has started moving toward tote but has not reached it`) — that is the OSS “event, not arrangement” rule; it beats any filter stack.
