Pipeline — how shots become 720×1280 episodes

Wavespeed alibaba/wan-2.7/text-to-video per shot (720×1280, LoRA weight 0.8, steps 28, CFG 6.5, dpmpp_2m) → Wan video-extend with first_frame/last_frame stitching (image-to-video fallback) → ffmpeg concat → ffmpeg -ss 1.2 -i scene.mp4 -vframes 1 -s 720x1280 poster.jpg → R2 videos/{slug}/ep{n}.mp4 + posters/{slug}/ep{n}.jpg → D1 episodes.posterUrl / videoUrl. LoRA IDs from docs/prompts.md + wan.ts TOP_NSFW_LORAS. Seeded picsum is wireframe watermark only; production replaces with Wan output.
